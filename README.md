### 🎯 Project 2 — Real-Time Fraud Detection *(Week 2)*
**Random Forest · Kafka · Redis · FastAPI · Docker · Grafana**

End-to-end fraud scoring on 284,807 real card transactions: Kafka streams the transactions, Redis caches, FastAPI returns a fraud score in 22ms, and Grafana monitors the service.

**Phase 2 rigour pass (in progress):**
- Leakage-free evaluation: stratified cross-validation with resampling inside each fold; out-of-fold PR-AUC 0.846
- Calibration checked: isotonic and Platt scaling did not beat the raw scores (PR-AUC 0.831 and 0.836 vs 0.846), so the raw scores are kept
- Next: a cost-based alert threshold, because a missed fraud costs far more than a false alarm

*Outputs a fraud score designed to feed a case-management queue, not just a prediction.*

### 🌍 Project 6 — Environmental Anomaly Detection + Time Series *(Week 6)*
**ARIMA · Prophet · LSTM (PyTorch) · Isolation Forest · Streamlit · FastAPI · Docker · AWS EC2**

End-to-end environmental monitoring pipeline trained on 11,998 real PM2.5 sensor readings from 5 Nairobi locations via OpenAQ. Answers two questions automatically for every hourly reading: What will PM2.5 be next? Is this reading dangerous?

**Key EDA findings:**
- PM2.5 peaks at **4am every day** — likely night burning trapped in cold air (a hypothesis, not tested here)
- **Friday** is consistently the worst day of the week
- Maximum spike: **469 µg/m³** on 2024-02-18 at 4am (one hourly reading), far above the WHO 24-hour guideline of 15 µg/m³
- 1.8% of all readings exceed the dangerous US EPA threshold of 55 µg/m³

| Model | RMSE | MAE | Type |
|---|---|---|---|
| **ARIMA ✅ Best** | **9.93** | **8.35** | Forecasting |
| LSTM (PyTorch) | 19.46 | 17.87 | Deep Learning |
| Prophet | 22.05 | 19.40 | Forecasting |
| Isolation Forest | — | — | Anomaly Detection |

**XGBoost · SHAP · ADASYN · DVC · RFM · FastAPI · PostgreSQL · Grafana · Docker · AWS EC2**
